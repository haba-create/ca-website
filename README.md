# SocialBoost - Bilingual Marketing Website

A modern, responsive one-page website for a social media marketing agency. Supports English and German languages.

## Features

- **Bilingual Support**: Full English and German translations with easy language switching
- **Modern Design**: Clean, professional UI with smooth animations
- **Fully Responsive**: Works on all devices (desktop, tablet, mobile)
- **Fast Loading**: Optimized performance with minimal dependencies
- **Railway Ready**: Configured for easy deployment to Railway.app

## Sections

- Hero with statistics
- Services (6 service offerings)
- About Us
- Portfolio/Case Studies
- Client Testimonials
- Contact Form

## Tech Stack

- Node.js + Express
- Vanilla HTML, CSS, JavaScript
- Google Fonts (Inter)

## Local Development

```bash
# Install dependencies
npm install

# Start the server
npm start

# Visit http://localhost:3000
```

## Deployment to Railway

1. Push this repository to GitHub
2. Connect to Railway.app
3. Railway will automatically detect Node.js and deploy

The app uses the `PORT` environment variable which Railway sets automatically.

## Environment Variables

- `PORT` - Server port (default: 3000, automatically set by Railway)
