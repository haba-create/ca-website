# Macrolinks Associates Website

An integrated approach to business - Worldwide support and consultancy for sustainable development.

## Features

- Bilingual support (English/German)
- Responsive design
- Scrolling text banner
- Railway.app ready

## Local Development

```bash
npm install
npm start
# Visit http://localhost:3000
```

## Deployment

Push to GitHub and connect to Railway.app for automatic deployment.
